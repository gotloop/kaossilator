# Korg Kaossilator: program categories and scale list

Transcribed from the reference card [KaossScalesBIG.jpg](./images/KaossScalesBIG.jpg).

## Program category list

| Category     | Display range |
| ------------ | ------------- |
| Lead         | `L.00`–`L.19` |
| Acoustic     | `A.20`–`A.29` |
| Bass         | `b.30`–`b.49` |
| Chord        | `c.50`–`c.59` |
| SE           | `S.60`–`S.79` |
| Drum         | `d.80`–`d.89` |
| Drum pattern | `P.90`–`P.99` |

The card adds: "For details on the programs, refer to the owner's manual."

## Scale list

The card spells every scale in the key of C. The **Semitones** column isn't on the card: it gives each note's offset from the tonic, so you can transpose the scale to any key. The top C (octave) is left out of that column.

Notes:

- "Diminish" and "Combination Diminish" are the card's spellings. They're the whole-half and half-whole diminished scales.
- 4TH is printed as `C F B♭ C`, which isn't a true stack of fourths (that would continue to E♭). This table follows the card.
